# Asking an agent from the Revelio view

Research checked on 19 November 2026. The **Ask the agent about this Part** button is currently a placeholder. One way to wire it is to extend Revelio’s webview message types so the button can send a question, the Flow and Part names, and the relevant Anchors to the VS Code extension host. [Flow page](../../packages/vscode-extension/webview/src/flow-page.tsx) · [Revelio message types](../../packages/vscode-extension/src/messages.ts) · [VS Code webview messaging](https://code.visualstudio.com/api/extension-guides/webview#passing-messages-from-a-webview-to-an-extension)

## Hand off to the agent’s VS Code extension

- **Codex.** Call `chatgpt.openSidebar` or `chatgpt.newChat` through `vscode.commands.executeCommand`. `chatgpt.addToThread` attaches a text editor selection to the current chat, and `chatgpt.addFileToThread` attaches the file. For context selected in the Revelio webview, copy the draft so the Builder can paste and send it in Codex. [Codex IDE commands](https://learn.chatgpt.com/docs/ide/commands#extension-commands) · [VS Code command API](https://code.visualstudio.com/api/extension-guides/command#programmatically-executing-a-command)
- **Claude Code.** Open `vscode://anthropic.claude-code/open?prompt=<encoded-draft>` with `vscode.env.openExternal` to fill an editable prompt. The optional `session` parameter resumes a saved conversation or focuses its open tab. An unknown session ID opens a fresh conversation. The extension and CLI share local history, and Anthropic warns against using the same conversation in two processes at once. [Claude Code URI handler](https://code.claude.com/docs/en/vs-code#launch-a-vs-code-tab-from-other-tools) · [VS Code URI API](https://code.visualstudio.com/api/references/vscode-api#env.openExternal) · [Shared history](https://code.claude.com/docs/en/vs-code#switch-between-extension-and-cli) · [Concurrent sessions](https://code.claude.com/docs/en/vs-code#the-conversation-is-still-open-somewhere-else)

These documented handoffs leave prompt submission and replies in the agent’s panel.

## Reach an agent already running in a terminal

- **Codex.** Since CLI 0.149.0, `codex queue --thread <id> --message <text>` can submit text to a session on the local Codex daemon or on an app server selected with `--remote`, regardless of which terminal displays it. For replies in Revelio, test connecting both clients to one App Server over a Unix socket. Start it with `codex app-server --listen unix:///path/to/codex.sock` and connect the terminal with `codex --remote unix:///path/to/codex.sock`. Verify that Revelio receives turn events for the same thread. [Codex 0.149.0 release](https://github.com/openai/codex/releases/tag/rust-v0.149.0) · [Queue command](https://learn.chatgpt.com/docs/cli/reference#codex-queue) · [App Server terminal connection](https://learn.chatgpt.com/docs/app-server#connect-the-cli-terminal-ui)
- **Claude Code.** An MCP Channel can push messages into a running, channel-enabled CLI session. Revelio would receive the messages Claude sends through a reply tool. Anthropic’s localhost demo uses this pattern. Channels are in research preview and require startup opt-in and eligible authentication. A custom channel needs a development startup flag or approval on the organization’s allowlist. The CLI’s `/ide` connection supplies editor context and diffs. [Claude Code Channels](https://code.claude.com/docs/en/channels#quickstart) · [Channel allowlists](https://code.claude.com/docs/en/channels#research-preview) · [IDE connection](https://code.claude.com/docs/en/vs-code#run-cli-in-vs-code)
- **Terminal handoff for either agent.** VS Code can pass a single line to a Builder-selected integrated terminal with `Terminal.sendText(text, false)`. The destination is whichever process has terminal input. The Builder confirms the agent is at its prompt and presses Enter. Shell integration exposes raw output from a tracked command. Arbitrary terminal output is available only through a proposed VS Code API. For an external terminal, the Builder can paste the draft or use `claude-cli://open` to open a new Claude Code terminal with an editable draft. [VS Code Terminal API](https://code.visualstudio.com/api/references/vscode-api#Terminal) · [Shell execution output](https://code.visualstudio.com/api/references/vscode-api#TerminalShellExecution) · [Proposed terminal output API](https://github.com/microsoft/vscode/blob/main/src/vscode-dts/vscode.proposed.terminalDataWriteEvent.d.ts) · [Claude Code terminal links](https://code.claude.com/docs/en/deep-links)

## Keep the conversation in Revelio

For chat inside the view, start a session from the extension host with Codex App Server or the Claude Agent SDK. Save the thread or session ID to continue the conversation later.

- **Codex.** The TypeScript SDK (`@openai/codex-sdk`) streams structured events with `runStreamed()` and reopens a saved thread with `resumeThread(id)`. `codex exec --json` and `codex exec resume` offer a subprocess version. For live text deltas, cancellation, and interactive approvals, use `codex app-server` over stdio. It is the protocol behind Codex’s own VS Code extension. [Codex TypeScript SDK](https://github.com/openai/codex/tree/main/sdk/typescript#streaming-responses) · [Non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode) · [Codex App Server](https://learn.chatgpt.com/docs/app-server)
- **Claude Code.** Use the TypeScript Agent SDK (`@anthropic-ai/claude-agent-sdk`) for streaming input and replies, or run `claude -p --output-format stream-json --verbose --include-partial-messages` and use `--resume <id>` for later turns. Anthropic directs third-party SDK integrations to API keys or supported cloud providers. [Agent SDK streaming input](https://code.claude.com/docs/en/agent-sdk/streaming-vs-single-mode) · [Claude Code programmatic CLI](https://code.claude.com/docs/en/headless) · [Authentication rules](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)

Local verification covered the installed extensions’ command manifests, the CLI help, and an offline `initialize` and `thread/start` exchange with Codex App Server 0.149.1. Prompt delivery to a live session and reply rendering in Revelio remain to be verified.
