# Revelio AI for VS Code

Understand the app your agent built, without reading its code. [Revelio](https://revelio-ai.dev) keeps a plain-words map of your app's Flows, Areas and Parts, checked against the code after every change. This extension will show that map in the editor.

It is not released yet. For now it opens a Revelio tab that says "Hello world": run **Revelio: Open** from the Command Palette.
